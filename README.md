# OZON ETERNAL

Шуточный roguelike по мотивам Hades про легендарного стримера и писателя Ozon671games.
Пиксель-арт, бои комната за комнатой, похмелье после каждой смерти.

> **⚠️ Это преальфа.** Контента пока мало: только начало пути, один босс и горстка врагов.
> Игра будет пополняться — новые уровни, боссы, напитки и отрывки «Тихого Дена» ещё впереди.
> Возможны баги и странный баланс — если что-то сломалось, напиши автору.

## Скачать

Последняя версия всегда здесь: **[Releases → latest](../../releases/latest)**.

| Система | Файл |
|---|---|
| macOS (Apple Silicon и Intel, macOS 11+) | `OZON-ETERNAL-mac.dmg` |
| Windows 10/11 (64 бит) | `OZON-ETERNAL-windows.zip` |

Ставить движок и что-то ещё не нужно.

## Установка на Mac

1. Скачай `OZON-ETERNAL-mac.dmg` и открой его двойным щелчком.
2. Появится окно: слева Озон, справа папка «Программы». Перетащи Озона на папку.
3. Закрой окно и извлеки диск «OZON ETERNAL» (правый клик → «Извлечь»).
4. Запусти игру из «Программ» или через Launchpad.

**При первом запуске** macOS скажет, что не может проверить разработчика. Это нормально:
у игры нет платной подписи Apple. Чтобы открыть:

1. В окне с предупреждением нажми «Готово».
2. Открой «Системные настройки» → «Конфиденциальность и безопасность».
3. Пролистай вниз — там будет строка про OZON ETERNAL. Нажми «Всё равно открыть»
   и подтверди паролем или Touch ID.

Это нужно сделать один раз. После обновления игры (новый .dmg → перетащить → «Заменить»)
macOS может спросить ещё раз — повтори то же самое.

## Установка на Windows

1. Скачай `OZON-ETERNAL-windows.zip`.
2. Распакуй архив (правый клик → «Извлечь всё…») в любую папку.
3. Запусти `OZON ETERNAL.exe`.

Если Windows покажет синее окно SmartScreen «Система Windows защитила ваш компьютер» —
нажми «Подробнее» → «Выполнить в любом случае». Игра не подписана сертификатом, поэтому
Windows её не знает.

## Управление

Играть можно на клавиатуре с мышью или на геймпаде (Xbox, PlayStation и совместимые).

| Действие | Клавиатура и мышь | Геймпад |
|---|---|---|
| Ходить | WASD | левый стик |
| Целиться | мышь | правый стик |
| Удар | ЛКМ | X |
| Усиленный удар | ПКМ | Y |
| Рывок | Пробел | A |
| Способность | Q | RB |
| Действие, подтверждение | E | A (рядом с предметом) |
| Назад | Esc | B |
| Пауза | Esc | Start |

Остальное игра подскажет сама.

## Прогресс и сохранения

Прогресс сохраняется сам. Чтобы начать с нуля, удали файл `save.json`:

- **Mac:** `~/Library/Application Support/Godot/app_userdata/OZON ETERNAL/`
  (в Finder: «Переход» → «Переход к папке…» и вставь путь)
- **Windows:** `%APPDATA%\Godot\app_userdata\OZON ETERNAL\`
  (вставь путь в адресную строку проводника)

## Для разработчиков

Игра сделана на Godot 4.6 (GDScript). Чтобы запустить из исходников: скачай
[Godot 4.6](https://godotengine.org/download) (обычную версию, не .NET), в нём Import →
`project.godot` → F5. Сборки для Mac и Windows собираются сами при каждом пуше
(`.github/workflows/build.yml`).

Дизайн-документ — `docs/GDD.md`. **Осторожно: там спойлеры всей игры.**
